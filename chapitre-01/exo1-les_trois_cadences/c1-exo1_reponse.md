# Exercice 1: Les trois cadences

## Durée d'une image au dixième de milliseconde à :

-72 Hz : 13.9 ms
-90 Hz : 11.1 ms
-120 Hz : 8.3 ms

## Lorsque je soustrait les huit millisecondes que prennent les capteurs, la transmission, la composition et l'affichage, il reste à mon code :
-72 Hz : 5.9 ms
-90 Hz : 3.1 ms
-120 Hz : 0.3 ms

| Cadence | Durée d'une image − 8 ms | Reste pour le code |
|---|---|---|
| 72 Hz | 13,9 − 8,0 | **5,9 ms** |
| 90 Hz | 11,1 − 8,0 | **3,1 ms** |
| 120 Hz | 8,3 − 8,0 | **0,3 ms** |
